Посещение сайта

Сайт размещён на GitHub Pages. GitHub сохраняет IP-адреса посетителей для обеспечения безопасности. Сроки хранения, обработку за пределами ЕЭЗ и меры защиты GitHub описывает в своей политике конфиденциальности.

Автор сайта не добавляет рекламу, аналитику и файлы cookie. При переходе по внешней ссылке действуют правила соответствующего сервиса.

Обновления по электронной почте

Адрес электронной почты, запись о подтверждении согласия и сведения о доставке писем используются для управления подпиской, отправки обновлений и подтверждения согласия. Письма отправляются на основании вашего согласия (ст. 6(1)(a) GDPR). Указывать адрес добровольно, он нужен только для подписки. Автоматизированные решения на этом основании не принимаются.

beehiiv Inc. (США) обрабатывает данные для формы, списка подписчиков и рассылки. Сервис может регистрировать технические сведения, в том числе IP-адреса, а в зависимости от настроек также открытия писем и переходы по ссылкам. Соглашение об обработке данных описывает меры защиты при передаче за пределы ЕЭЗ, включая стандартные договорные положения ЕС. Дополнительные сведения или копию этих условий можно запросить по адресу выше.

beehiiv · Data Protection Addendum

Данные активной подписки хранятся, пока она действует. Согласие можно отозвать в любой момент по ссылке в каждом письме или написав на адрес выше. Отзыв согласия не влияет на законность предшествующей обработки. Минимальная запись об отписке может храниться до закрытия списка, чтобы предотвратить повторную рассылку (ст. 6(1)(f) GDPR).
